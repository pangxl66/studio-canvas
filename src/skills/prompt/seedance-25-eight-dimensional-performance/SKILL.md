# Seedance 2.5 + 八维表演

先按 Seedance 2.5 v10 生成完整基础 PromptOutput，随后冻结基础卡。本 Skill 只生成【表演】和【时间轴】的替换正文，由应用程序化拼接回基础卡。这是模块组合，不是让模型重写或修复整张 v10 Prompt。

## 接管边界

- 冻结 v10 的挂载、生成规格、摄影机、机位与构图、起幅、光学效果、声音/对白、落幅、连续性和限制；最终成品中这些区块必须与基础卡原文一致。
- 将逐角色八维分析保留在内部，不把目标、潜台词、触发锚点、表演弧线、面部可读性和镜尾状态逐项输出给视频模型。
- 让【表演】只保留精简的整体表演调性、人物主次、关系、动作克制程度和非人主体表演原则。
- 让【时间轴】成为唯一带时间戳、唯一承载单人表演细节、唯一执行八维变化的模块。
- 不新增剧情、人物、台词、动作结果、心理事实、道具或空间关系。
- 模型返回的是 `shotModules` 内的 `performance` 与 `timeline`；按 v10 基础卡顺序逐项对应，不要求也不读取 `shot_id`；不返回完整 seedanceCard，避免模型改写冻结区块。

## 内部导演计划

对每个重要行动或反应主体在内部建立：

1. 目标。
2. 潜台词；没有差值时使用“潜台词与表面行动一致”。
3. 可见或可听的触发锚点。
4. 起始基准 → 第一反应 → 调整 → 镜尾残留的表演弧线。
5. 面部可读性及景别允许的表情强度。
6. 可由下一镜承接的镜尾状态。

读取[八维模型](references/eight-dimensions.md)、[AU/FACS 内部校准](references/facial-au-facs.md)、[身体与声音](references/body-voice-reactions.md)和[类型与情绪](references/genre-and-emotion.md)。这些内容只用于推演，不作为独立分析报告输出。

## 【表演】输出规则

- 用一段紧凑文字说明整体表演调性、主次关系和各主体的核心方向。
- 多人镜头明确谁主导当前节拍、谁维持低强度关系反应。
- 非人或面部不可读主体用一句话声明改用机械、姿态、距离、节奏、灯光或声音信号。
- 禁止时间戳、逐角色字段清单、动作步骤、微表情步骤和第二套时间线。
- 纯空镜写“无行动主体，不设计人物表演”。

推荐形态：

```text
【表演】
整体采用克制、写实的任务导向表演。角色A主导行动方向；角色B经历“处理当前任务—察觉变化—立即跟上”的短促反应；非人角色C最后响应，以机械朝向、启动停顿和速度变化表达跟随。当前景别只保留可辨认的低强度表情，重点依靠视线、头部、重心、步频和角色距离传达状态。
```

## 【时间轴】输出规则

- 从 0.0s 开始，连续、无重叠、无空洞，并准确结束于真实总时长。
- 只在事件、触发或表演状态真实变化时切段。
- 在对应时间段直接写出每个角色的动作与表演，不再重复“目标、潜台词、表演弧线”等分析标签。
- 将内部目标转译为身体方向和动作选择，将触发转译为感知与认知延迟，将弧线转译为第一反应、调整和镜尾残留。
- 根据实际可见性选择自然语言面部变化、视线/头部、身体/手部、重心/步幅、呼吸/发声/停顿或非人机械信号；不要机械堆满所有通道。
- 整条【时间轴】必须包含真实可见或可听的表演增量，不能通篇只有剧情动作。允许某一短段只负责建立事件或触发，但紧邻后续段必须承接该触发并写出角色反应。
- 只引用 v10 已确定的摄影和声音事实，不在时间轴里重新设计摄影机、构图、光学、环境声音或对白。

时间段推荐形态：

```text
[起始秒–结束秒]
角色A因当前触发发生可见变化并推进动作；写清视线或头部、重心或手部、表情或呼吸中当前真正发生的变化。与此同时，角色B维持关系所需的低强度反应。段末明确形成的动作与表演状态。
```

## 强制原则

- AU/FACS 只用于内部校准；最终 seedanceCard 出现 `AU4`、`AU7`、`FACS` 等编号即失败。
- 重要且面部可读的人类角色必须在【时间轴】中出现符合景别的自然语言面部变化；中远景使用低强度校准。
- 近景、中近景或特写中的可读人脸必须优先于泛化身体信号：整条【时间轴】至少覆盖两个不同面部区域（眉部、眼睑、面颊、鼻部、嘴唇、下颌等）的具体变化，最后一个时间段至少保留一个面部区域的明确残留状态。
- “紧张、无语、警觉”等情绪形容词以及视线、抬头、停顿、肩部或呼吸变化不能单独充当具体表情；必须写出可被摄影机读到的面部动作及强度或变化方向。
- 非人、机器人、面具、头盔或不可见面部不得新增人类器官，改用真实机械、姿态、距离和反馈变化。
- 眼神先感知，头部和身体随后响应；除非强刺激，不要让眼、头和躯干机械同步。
- 多人镜头每个表演节拍只设一个主要焦点，其他角色保留关系所需的低强度反应。
- 镜尾表演状态必须与 v10【最终落幅】一致，不得提前启动下一镜动作。
- 必须在 v10 基础卡冻结后完成内部规划；只替换两个模块正文，禁止重写完整 seedanceCard。

按照[输出契约](references/output-contract.md)返回两个模块正文，由应用完成确定性拼接。
