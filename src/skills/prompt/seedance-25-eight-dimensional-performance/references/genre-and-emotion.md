# 类型调性与情绪转换

只使用项目约束、角色设定和当前镜头可证实的类型信息。没有明确类型时采用写实、克制、低噪声表演。

## 类型校准

- 写实剧情：减少信号数量，保留准确触发、最小泄露和镜尾余波。
- 喜剧：人物认真执行目标；笑点来自误判、节奏、阻力和结果，不靠随机鬼脸。
- 惊悚/恐怖：视线搜索、头部角度、动作中断、呼吸控制和距离变化优先。
- 动作/追逐：目标、重心、路径、受力、速度变化和恢复优先，面部变化保持简洁。
- 爱情/亲密：视线接触或回避、距离、呼吸、手部犹豫和声音尾部变化优先。

## 情绪弧线结构

- 镇定 → 察觉异常 → 短暂泄露 → 强行恢复 → 留下余波。
- 防御 → 试探 → 确认威胁 → 收紧边界。
- 期待 → 误读 → 掩饰尴尬 → 留下不安。
- 愤怒被压住 → 语气平直 → 手部或下颌泄露张力 → 镜尾未释放。
- 害怕 → 搜索出口 → 做出决定 → 带着余悸行动。
- 悲伤被压住 → 维持任务 → 触发后短暂失守 → 重新控制但呼吸未恢复。
- 喜剧严肃执行 → 阻力升级 → 坚持错误判断 → 结果反噬。

这些只表示先后节拍，不携带时间戳，也不得覆盖当前角色事实。

## 混合情绪

混合情绪必须有主次。选择一个主目标和一个泄露信号，不让矛盾情绪的全部信号同时满强度。

- 开心但害怕：笑意出现，视线仍检查风险，手部张力未释放。
- 礼貌但嫉妒：嘴角维持礼貌弧度，但眼周没有同步笑意；眼神追踪对方，身体保持距离。
- 生气但受伤：眉心与眼睑保持克制张力，眉内侧和嘴角轻微泄露受伤感，声音仍然锋利。
- 想哭但维持专业：呼吸短暂停顿、下颌重新固定、手部继续完成任务。
