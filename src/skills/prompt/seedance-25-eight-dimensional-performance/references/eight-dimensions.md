# 八维表演模型

对每个重要行动主体和反应主体分别设计。不要把多人合并成一段模糊的群体表演。

## 1. 表演调性 Performance Tone

先决定写实程度、克制程度、动作幅度、节奏和类型调性。调性控制所有后续维度，不得让不同维度互相打架。

- 写实：减少信号数量，保留准确触发、微小泄露和真实身体惯性。
- 喜剧：人物必须认真执行目标；笑点来自节奏、误判、阻力和结果，不靠随机鬼脸。
- 惊悚：延迟反应、空间警觉、视线搜索和呼吸控制优先。
- 动作：目标、重心、受力、路径和恢复优先，面部信号保持简洁。
- 情感戏：潜台词、视线回避、呼吸、声音和镜尾余波优先。

## 2. 目标 Objective

写角色此刻具体想得到、阻止、隐藏、确认、靠近、摆脱或维持什么。目标必须能转化为身体方向和动作选择。

目标不等于剧情摘要。使用“想让对方停下”“想隐藏慌乱”“想赶上队伍”，不要使用“推进剧情”“表现紧张”。

## 3. 潜台词 Subtext

写表面行为与真实意图之间的差值。没有差值时明确写“潜台词与表面行动一致”，不要强造秘密。

潜台词必须来自已知人物关系、台词或动作上下文。没有依据时只描述可证实压力。

## 4. 触发 Trigger

写导致表演状态变化的可见或可听事件，例如一声异响、对方转身、某个词、道具状态改变或距离缩短。

触发只是事件锚点，不在【表演】中分配秒数。具体发生时间交给【时间轴】。

## 5. 表演弧线 Acting Arc

必须形成：

`起始基准 → 触发后的第一反应 → 控制/调整/失控 → 镜尾残留`

第一反应应先于有意识调整，除非角色已经预知事件。控制成功也要留下最小余波，例如呼吸未完全恢复、手指仍紧、视线仍避开。

## 6. 面部与视线 Face / Eyes

描述眉眼、眼睑、视线落点、眨眼、下颌、唇部、头部角度与转向节奏。必须符合景别和遮挡。

- 特写：内部允许精确校准细微触发变化，最终只写自然语言面部动作。
- 近景：使用少量自然语言面部变化、视线和呼吸。
- 中景：使用低至中强度眉眼、唇部或下颌变化，加头部与视线行为。
- 中远景/全景：只保留摄影机能辨认的最小表情变化，重点转向头部、身体、步态和空间关系。

## 7. 身体与手部 Body / Hands

描述重心、肩颈、胸腔、躯干朝向、步幅、速度、惯性、手指张力、抓握、触碰力度和动作抑制。

手部动作必须服务目标或泄露潜台词。禁止无原因挥手、摸脸、整理衣服、反复握拳。

## 8. 呼吸、声音与停顿 Breath / Voice / Pause

描述吸气、屏息、呼气、吞咽、音量、气息支撑、语速、断句、尾音、沉默和停顿用途。

没有对白也要判断呼吸是否可见或可听。不要添加原文没有的台词、喘息、哭喊或笑声。

## 镜尾状态 End State

镜尾状态必须能被下一镜继承，包括姿态、重心、视线、手部、道具、呼吸、声音、情绪余波、动作阶段和角色距离。

镜尾状态必须与 v10【最终落幅】一致，不得提前启动下一镜动作。
