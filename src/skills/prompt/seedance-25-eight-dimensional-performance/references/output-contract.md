# v10 冻结基础卡的局部接管契约

本契约只对已冻结 v10 seedanceCard 的【表演】与【时间轴】生效。模型仅返回这两个模块的替换正文，由应用确定性拼接回完整 v10 卡。不允许模型输出、修复或改写其他 v10 模块。

## 运行时输出格式

```json
{
  "shotModules": [
    {
      "performance": "只包含【表演】正文，不带标题",
      "timeline": "只包含【时间轴】正文，不带标题"
    }
  ]
}
```

`shotModules` 只按 v10 基础卡的镜头顺序逐项返回。不要输出、推断或校验 `shot_id`；应用会按数组顺序自动绑定到原镜头。

应用只替换两个区块的正文。拼接前后对 v10 基础卡做冻结区域指纹比较；除【表演】和【时间轴】外，任何字符变化都视为失败。

## 唯一时间权威

所有秒数只进入 v10【时间轴】。【表演】禁止出现时间戳、按秒排列的表演时间线、第二套起止时间或总时长。

原 Performance Director 中带秒数的示例只能作为先后节拍理解。先在内部建立无时间戳角色计划，再直接编译进 v10 的唯一时间轴。

## 内部逐角色计划：不得输出

对每个重要主体在内部确认：

- 目标。
- 潜台词。
- 触发锚点。
- 表演弧线。
- 面部可读性。
- 镜尾状态。

这些字段用于决定表演，不得以“角色A：目标：……潜台词：……”的分析卡形式进入最终 seedanceCard。

## 【表演】固定结构：精简总则

```text
【表演】
整体表演调性；当前节拍的人物主次和关系；各主体的核心表演方向；景别允许的表情强度；非人主体采用的替代表演原则。
```

要求：

- 纯空镜、无人环境镜头及无行动主体镜头不进入八维模块，直接保留 v10 原卡；混合任务按镜头筛选。
- 通常写成一个紧凑段落，不逐角色展开字段清单。
- 不展开面部、视线、身体、手部、重心、呼吸或声音的逐步变化。
- 不重复剧情动作，不与【时间轴】竞争执行权。

## 【时间轴】固定结构：角色执行层

```text
【时间轴】
[起始秒–结束秒]
事件/触发；角色A的动作与可见可听表演变化；角色B维持关系所需的反应；非人主体的机械或姿态反馈；段末状态。
```

每个时间段根据当前镜头真正能拍到、听到的内容，选择以下通道：

- 自然语言面部变化。
- 视线与头部。
- 身体、重心、步幅与手部。
- 呼吸、发声、台词状态或停顿。
- 非人主体的机械、姿态、距离、节奏、灯光或声音反馈。

不要要求每段堆满所有通道。整条时间轴必须出现真实表演增量并保持明确的主要表演焦点；允许短段只建立事件或触发，但紧邻后续段必须承接并写出可见或可听反应。

## 编译规则

1. 内部完成逐角色目标、潜台词、触发、弧线、面部可读性和镜尾状态。
2. 将共同的调性、主次和关系压缩进【表演】。
3. 读取 v10 已确定的动作顺序和真实总时长。
4. 只在真实变化点切分时间段。
5. 将目标转译为动作选择，将触发转译为感知与认知延迟，将弧线转译为第一反应、调整和镜尾残留。
6. 在每段直接写角色姓名与可执行变化，不复制内部字段标签。
7. 不改变 v10 的挂载、生成规格、摄影机、构图、起幅、光学效果、声音/对白、最终落幅、连续性和限制。
8. 返回两个模块正文后由应用程序化拼接；禁止让模型重写完整基础卡。

## 失败条件

- 【表演】出现时间戳。
- 【表演】输出逐角色目标、潜台词、触发锚点、表演弧线、面部可读性或镜尾状态清单。
- 【表演】与【时间轴】重复展开相同动作。
- 重要且面部可读的人类角色没有在【时间轴】中出现符合景别的自然语言面部变化。
- 近景、中近景或特写的可读人脸只写抽象情绪、视线、抬头或停顿，没有至少两个不同面部区域的具体变化。
- 近景、中近景或特写的最后一个时间段没有保留至少一个具体面部区域的镜尾残留状态。
- 最终 seedanceCard 泄漏 AU/FACS 编号。
- 非人主体被新增人类器官，或缺少机械、姿态、距离、节奏、灯光或声音反馈。
- 整条时间轴只有剧情动作，没有任何可见或可听的表演增量。
- 时间轴不连续、重叠、有空洞或未覆盖真实总时长。
- 时间轴遗漏内部计划中的关键触发、第一反应、调整或镜尾残留。
- 镜尾状态与最终落幅冲突。
- 新增剧情、台词、人物、器官或动作结果。
- 模型返回了完整 seedanceCard 或其他 v10 模块，而不是 `shotModules` 中的两个替换正文。
- 程序化拼接后，冻结区域指纹与 v10 基础卡不一致。
- 在两个接管模块内重新设计摄影机、构图、光学、环境声音或对白。
